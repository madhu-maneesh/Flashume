# Flashume
An AI-Powered Resume Parser and ATS Score

FlashFume is an AI-powered full-stack web application that enables users to upload their resumes, receive detailed ATS scores and Users can also compare their resumes with others to understand strengths, weaknesses, and get personalized improvement suggestions. Built using the MERN stack and integrated with Gemini AI and Dialogflow, FlashFume bridges the gap between career optimization and intelligent automation.

##  Features

- **Drag-and-drop Resume Upload** (PDF/DOCX support)
- **AI Integration** (Gemini 1.5 Flash) for:
  - Resume Parsing
  - ATS Scoring
  - Skill & Keyword Matching
  - Resume Comparison
- **One-to-one Resume Comparison** with insights
-  Responsive UI with clean design
- Backend-to-Frontend communication for real-time updates
- **Get Role Based Suggestions**
- Suggests the Missing Skills
- **Analyzes the Carrer Gap**

## Tech Stack

- **Frontend:** React, Tailwind CSS, React Router
- **Backend:** Node.js, Express.js
- **AI Services:** Gemini 1.5 Flash (Google AI), Dialogflow (chatbot assistant)
- **Other Tools:** Multer, PDF-Parser, Mammoth, Axios
